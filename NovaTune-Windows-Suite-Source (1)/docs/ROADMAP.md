# Delivery roadmap

## Phase 1 — safe diagnostics foundation (included)

Dashboard telemetry, Smart Scan, explainable health scores, preview cleanup, restore point gate, quarantine/undo, read-only startup checks, basic disk status, and repair command planning.

## Phase 2 — Windows breadth

ETW-based boot analysis, Windows Update and Defender health providers, battery report parsing, Storage Sense integration, event log correlation, browser profiles, game launcher caches, scheduled automation, HTML/JSON/CSV reports, and file treemap.

## Phase 3 — hardware and drivers

Signed privileged broker, vendor sensor integrations, NVMe/SATA SMART pass-through, SSD wear normalization, driver backup/export through DISM/PnPUtil, verified catalog-only updates, and rollback testing.

## Phase 4 — commercial hardening

Residual uninstaller with snapshots, signed MSIX installer/updater, localization QA, accessibility audit, crash reporting with consent, performance budgets, security audit, privacy policy, telemetry controls, licensing, and staged release channels.

## Phase 5 — opt-in AI

Prefer an on-device model where supported. Cloud analysis must be disabled by default, redact usernames/paths/network identifiers, show the exact payload, and require per-report consent.
